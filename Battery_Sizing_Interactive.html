The mathematical decision function

For each positive battery capacity, simulate all 8,760 hours and recommend the one with the lowest equivalent annual cost. The 0 kWh case is solar without a battery: it is retained only as a financial benchmark, not an eligible battery capacity. A recommended battery is not necessarily financially worthwhile relative to buying no battery.

Eb* = arg min Eb ∈ ℬ { Cgrid(Eb) + AEC(Eb) }
Cgrid = Σt=1…8760 ( Timport,t × Eimport,t − TFIT,t × Eexport,t )
AEC = [Cinstalled − Ssubsidy] × CRF(r,L) + O&M

Simple worked example from the report

This separate two-hour arithmetic example uses the corrected equations, but is not a sample from the 8,760-hour dataset.

Hour 1 — Solar surplus charges battery

10 kWh battery initially holds 4.00 kWh. PV = 5.0 kWh; load = 1.5 kWh. With charging efficiency 0.95, rated power 5 kW and maximum SOC 95%:

Surplus = 5.0 − 1.5 = 3.5 kWh
Charge = min(3.5, 5, (9.5−4)/0.95)
Charge = 3.5 kWh
B′ = 4 + (0.95 × 3.5) = 7.325 kWh
SOC′ = 100 × 7.325/10 = 73.25%

Hour 2 — Stored energy supplies load

PV = 0 kWh; load = 4.0 kWh. The battery begins this hour at 7.325 kWh and has a 10% minimum SOC:

Deficit = 4.0 − 0 = 4.0 kWh
Discharge = min(4, 5, (7.325−1)×0.95)
Discharge = 4.0 kWh
B′ = 7.325 − 4/0.95 ≈ 3.114 kWh
SOC′ ≈ 31.14%

Interpretation, data sources & references

How to read the results

The priority rule is self-consumption-first: use PV directly, charge with solar surplus, discharge to cover deficits, then transact with the grid. This is not tariff-aware scheduling optimisation. The price sliders only value the resulting flows; they do not schedule battery energy to higher-priced hours. This distinction is important for time-of-use tariffs.

What the data actually establish

The thesis reports annual PV generation (10,539 kWh), household demand (5,780 kWh), direct solar use (2,668 kWh), excess PV (7,871 kWh) and grid imports (3,112 kWh) for a battery-free scenario. The simulated chronological data here were separately reconstructed and calibrated to those totals. A calibrated reconstruction cannot establish the actual optimum for the missing original dataset. With different hourly patterns or costs, the recommendation can change.

Limitations and next steps

For dissertation validation, load a real CSV of 8,760 consecutive, time-aligned hours; verify climate, dates/time zone and PV AC boundary; use actual hardware ratings, battery quote, retailer tariffs and verified subsidy eligibility; and record all sensitivity cases. The financial model uses CRF for equivalent annual ownership, assumes PV-only battery charging, flat tariff inputs, zero curtailment and fixed efficiencies. For degradation, replacement, variable tariffs, grid export caps or TOU-optimal dispatch, extend the model first.
